# wg-telegram

Telegram-бот для управления **уже установленным wg-easy 15** на том же сервере.
Подходит для Ubuntu 24.04, Python 3.12 и systemd. Python запускается из venv;
отдельная компиляция в исполняемый бинарник не нужна.

## Возможности

- Создание клиента и получение `.conf` и QR-кода.
- Список устройств с пагинацией по 8 строк.
- Включение и отключение клиента.
- Удаление с одноразовым подтверждением, действующим 2 минуты.
- Текущие счётчики трафика и последний handshake.
- Только личный чат администратора; проверяется ID отправителя и чата.
- Пересылка файлов и QR разрешена по умолчанию.
- Автозапуск systemd, отдельный пользователь без прав root и доступа к Docker.

## Самая простая установка

Установка непосредственно из GitHub:

```bash
curl -fL https://raw.githubusercontent.com/ECL1SSI/wg-telegram/main/setup-wg-telegram.sh -o /tmp/setup-wg-telegram.sh
sudo bash /tmp/setup-wg-telegram.sh
```

Или скачайте `setup-wg-telegram.sh` из артефакта GitHub Actions или из полученного
пакета и перенесите на сервер. Затем:

```bash
sudo bash setup-wg-telegram.sh
```

Установщик сам установит зависимости, спросит недостающие настройки,
проверит API wg-easy и Telegram и запустит службу. Существующий
`/opt/wg-telegram/.env` используется повторно. Токен и пароль при вводе скрыты.
Нужны доступ к репозиториям Ubuntu, PyPI, Telegram и локальная панель wg-easy.

При наличии исходников:

```bash
sudo bash install.sh
```

Для своего нового бота получите токен у @BotFather и числовой Telegram ID.
После установки отправьте боту `/start`. Кнопка «Создать подключение» запросит
имя устройства и пришлёт конфигурацию и QR. Каждому устройству создавайте
отдельного клиента.

## Настройка wg-easy

wg-easy должен быть установлен и настроен заранее. Проверенная пользователем
версия: **15.4.0**, Basic Auth на `/api/client`. API wg-easy нестабилен:
после обновления сервера совместимость может измениться.

Публикуйте веб-панель только на loopback:

```yaml
ports:
  - "51820:51820/udp"
  - "127.0.0.1:51821:51821/tcp"
environment:
  INSECURE: "true"
```

Для входа в панель используйте SSH-туннель или HTTPS reverse proxy.
Бот поддерживает локальный Basic Auth; при включённой 2FA этот API-способ
может быть недоступен. Установщик не меняет Docker, wg-easy, UFW и VPN-клиентов.

## Настройки

```bash
sudo nano /opt/wg-telegram/.env
sudo systemctl restart wg-telegram
```

Поля описаны в `.env.example`. Для разрешения пересылки:

```dotenv
PROTECT_CONTENT=false
```

Изменение применяется к новым выдачам. Повторно нажмите «Конфиг + QR».
Получатель конфигурации получает доступ к VPN. Бот отправляет приватные ключи
через личный чат Telegram; не размещайте их в публичных чатах и репозитории.

## Диагностика и обновление

```bash
sudo systemctl status wg-telegram --no-pager -l
sudo journalctl -u wg-telegram -n 50 --no-pager -o cat
sudo systemctl restart wg-telegram
sudo systemctl stop wg-telegram
```

Для обновления запустите новый `setup-wg-telegram.sh`. `.env` сохраняется,
предыдущие файлы кода копируются в `*.backup-<timestamp>`.
После тайм-аута создания клиента сначала проверьте список: запрос мог успеть
выполниться. Автоматические повторы создания отключены. Обновления Telegram
отмечаются обработанными до изменения VPN, чтобы избежать повторного создания
после сбоя; при аварии ответ может потеряться — тогда проверьте список.
Трафик — текущие счётчики интерфейса, не постоянная помесячная статистика.

## Проверка и сборка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m compileall -q bot.py configure.py build.py
bash -n install.sh
python3 build.py
bash -n dist/setup-wg-telegram.sh
```

Результат в `dist/`: один установщик и архив исходников. GitHub Actions
автоматически выполняет проверки и сохраняет пакет `wg-telegram-installers`
для скачивания. Модульные проверки используют заглушки API; живые создание,
скачивание и удаление проверяются на вашем сервере после установки.

Токены, `.env`, конфиги, изображения и venv исключены из Git. Пакет не содержит
персональных настроек и не включает исходники самого wg-easy.
